# Tableau data files
Generated by `notebooks/01_credit_risk_eda_and_modeling.ipynb` (section 10). Re-run the notebook to regenerate.

| File | Description |
|---|---|
| `borrower_risk_scores.csv` | One row per borrower: cleaned attributes, bands, segment, out-of-fold predicted probability of default (`predicted_pd`), `risk_band`, `risk_decile`, `model_decision` |
| `segment_summary.csv` | Default rate per payment-history x utilization x age segment (>= 300 borrowers) |
| `risk_decile_lift.csv` | Lift table by predicted-risk decile |
| `model_comparison.csv` | ROC AUC / PR AUC / KS on the 20% hold-out set |
| `feature_importance.csv` | Permutation importance (drop in ROC AUC) |

`predicted_pd` comes from 5-fold cross-validation, so every borrower is scored by a model that never saw them.
